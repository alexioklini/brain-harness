# Brain 控件

[English](README.md) | 中文

## 概述

此浏览器插件在共享输入框上方添加对话模式和项目菜单，并提供隐私与中央工具证据对话框及侧边栏中央计划任务和退出登录控件。它复用现有插槽、资源模型和界面基础组件。读取和修改均通过已认证的 Brain 网关；浏览器不会收到服务凭据。

<a id="behavior"></a>
## 行为

网关按账户及对话分别保存模式和项目选择。MoA 选择中央 Router 编排。深度搜索通过工作进程记录到日志的系统提示组装加入证据研究指令；工具发现和执行仍全部集中进行。推理时重新检查项目访问权限。隐私读取根据已认证账户及当前对话派生会话标识。未知测量值保持可见，已测量为零的辅助计数不显示。

中央任务对话框列出当前账户的任务，支持创建、日历编辑、暂停或启用以及立即执行。模型来自 Brain 的模型目录；更新保留附件和连接器等服务字段。

工具对话框显示最近一次推理请求中由服务报告的执行状态、参数和结果。这是执行证据，而不是已启用工具目录。读取或保存失败时显示错误和重试控件。退出登录使本地网关登录失效。此包仅由 Brain 工作进程补丁挂载，不修改上游默认界面。

<a id="model-experience"></a>
## 模型体验

### 对话选择

#### 模型看到什么

`chat`、`moa` 和 `research` 模式选择及项目选择发送到账户网关。项目和研究指令通过工作进程记录的系统提示组装传递给模型。控件不添加本地工具。

#### Token 影响

项目和研究指令消耗实际提示 Token；隐私和工具证据对话框不增加 Token。

#### KV Cache 影响

修改项目指令或研究模式可能改变提示前缀。

## 已知限制与待办工作

<a id="known-limitations-and-deferred-work"></a>

- 此包尚未提供项目创建和语料管理。真实研究、MoA、隐私和多账户验收仍待完成；本地组件检查不等同于模型验收。

<a id="dev-note"></a>
### 开发备注

资源提供程序校验外部 JSON，并在最后一个订阅者离开时取消读取。网关修改请求由插件生命周期管理。
